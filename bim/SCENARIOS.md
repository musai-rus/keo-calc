# Реестр проверяемых сценариев BIM

Новый пример модели добавляет общий сценарий и синтетическую регрессию, а не исключение по URN, названию проекта или номеру помещения. Реальная модель и её дампы здесь не хранятся. Перечень открыт: неизвестный случай остаётся диагностикой, а не подтверждённым исходным данным.

| Сценарий | Требуемое поведение | Регрессия / предел |
|---|---|---|
| SPA сохранила ссылку на отключённый Viewer | Отказ до извлечения; перезагрузка может создать новый корректный экземпляр | `test-viewer-binding.js`, `test-lifecycle.js` |
| Несколько Viewer или моделей, скрытый/2D вид, незавершённая загрузка | Не выбирать первый объект; остановить расчёт с причиной | `test-viewer-binding.js` |
| Навигация/смена модели во время async или после готового результата | Отменить результат и метаданные; старый callback не меняет новую панель | `test-lifecycle.js` |
| По общим спальням или смешанным функциям получен tentative/ambiguous/unknown тип | Сохранить предварительный КЕО, отложить норму/соответствие до ручного подтверждения; экспорт не обходит барьер | `test-purpose-confidence.js`, `test-purpose.js` |
| Экспорт ru/en, двуязычные значения, переименованный displayName | Служебный CategoryId/BuiltInCategory важнее точного запасного имени; не искать подстроку в семействе | `test-categories.js` |
| Неизвестный, пользовательский или противоречивый идентификатор категории | Явное unknown; известное имя не обходит неизвестный ID | `test-categories.js` |
| Rooms, MEP Spaces и Areas присутствуют одновременно | Считать отдельно; Spaces/Areas не подменяют Rooms | `test-categories.js` |
| Rooms есть только в базе свойств, без fragments | Сохранить запись и единицы; отсутствие геометрии не означает отсутствие Room | `test-categories.js`; native границы не подтверждены |
| Строковое имя уровня выглядит числом | Сохранить строковое значение; не путать с object reference dataType=11 | `test-categories.js` |
| Уровень неоднозначен или отсутствует | Не придумывать связь; Room остаётся с предупреждением | `test-categories.js`, `test-context.js` |
| Единицы площади/длины неизвестны | Предупреждение вместо молчаливой подстановки единиц Viewer | `test-bim.js`, `test-lantern-properties.js` |
| По площади подходят несколько контуров / есть только восстановленный срез | Не объявлять native контур подтверждённым; показать неизвестные контуры и причины | `test-room-diagnostics.js`, `test-confirmed-perimeter.js`, `test-geometry-proof.js` |

Распознавание категорий и наличие Rooms не подтверждают точность координат экспортёра, соответствие физическим границам, нормативный выбор расчётной точки или окончательную достоверность КЕО. Эти проверки остаются отдельными.
