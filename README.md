# Калькулятор КЕО

Веб-калькулятор проверочного расчёта коэффициента естественной освещённости (КЕО) по СП 367.1325800.2025 и СП 52.13330.2016: боковое освещение, зенитные и шахтные фонари, фонари-надстройки, комбинированное освещение. Разбор формул на экране и PDF-отчёт с рамкой и основной надписью.

## Ссылки

- **Калькулятор:** https://musai-rus.github.io/keo-calc/
- **КЕО по модели в Autodesk Viewer (кнопка-закладка и инструкция):** https://musai-rus.github.io/keo-calc/bim.html

Открываются без входа. Сайт публикуется GitHub Pages из папки `docs/` ветки `main`.

### КЕО по модели — коротко

1. Откройте https://musai-rus.github.io/keo-calc/bim.html и перетащите кнопку «КЕО по модели» на панель закладок Chrome.
2. Откройте модель на [viewer.autodesk.com](https://viewer.autodesk.com), выберите вид **3D**.
3. Нажмите закладку — справа появится панель с КЕО по помещениям, на плане — заливка и метки.

Экспериментальная версия, нормативная точность на моделях не подтверждена. Ограничения:

- контуры помещений восстанавливаются по срезу модели на высоте 1 м; помещения без линии разделения опознаются по площади — при неоднозначности выбор за пользователем;
- расчётное пространство — физический объём: помещения без сплошной стены между ними (группа + спальня) считаются вместе, перегородка остаётся препятствием для света; коридоры, холлы, вестибюли и ЛК автоматически не объединяются;
- площадь берётся из свойства Area помещения Revit с явным переводом единиц и сверяется с контуром; сверка с листом экспликации не выполняется (листы в экспорте — PDF без привязки к помещениям);
- фонари — стекло, обращённое вверх, или элемент с «фонарь/зенит/skylight» в имени (в т. ч. семейства «Окна» в кровле, вложенные семейства; перекрытие без вырезанного проёма под фонарём принимается вырезанным — с пометкой); тип фонаря, кроме явного плоского зенитного, подтверждает пользователь; круглые фонари считаются по (8.3), размеры шахты — из параметров семейства (Diameter_Inside / Diameter_Bottom), если они есть; параметры шахты, τ и отражение стенок — допущения, показанные в карточке; затенение фонаря окружающими конструкциями только отмечается (в Б.3 не учитывается);
- ориентация — по северу модели (refPointTransformation) или ручному вводу; источник показан в карточке;
- кладовые и другие помещения без нормы не объединяются с нормируемыми автоматически; закрытая дверь разделяет объёмы;
- результаты предварительные (статусы со «*»), пока проверка на модели не завершена; независимая проверка бокового света — `node bim/verify-side.js`.

## Структура
| Файл | Назначение |
|---|---|
| `engine.js` | Расчётное ядро (Б.1, Б.2, Б.3, Б.4), эмуляция графиков Данилюка |
| `data.js` | Оцифрованные таблицы СП (генерируется `data/build_data.py`) |
| `model.js` | Состояние формы → расчёт → модель отчёта |
| `report.js`, `pdfwriter.js`, `fonts.js` | Генерация PDF без внешних библиотек |
| `schemes.js` | Схемы план/разрез (SVG и PDF) |
| `app.html`, `app.js` | Интерфейс |
| `build.py` | Сборка: `dist/keo.html` (claude.ai) и `docs/index.html` (сайт) |
| `bim/` | КЕО по модели в Autodesk Viewer: `spaces.js` (единицы, состав пространств, видимость — без Viewer), `geom.js` (срез, контуры, проёмы, фонари, затенение), `calc.js` (исходные данные калькулятора: боковое, верхнее, комбинированное), `app.js` (панель, заливка, метки, решения); тесты `test-bim.js`; сборка `bim/build.sh` → `docs/keo-bim.js` |
| `docs/` | Сайт: `index.html` (калькулятор), `bim.html` (кнопка-закладка), `keo-bim.js` |
| `test.js` | Контрольные расчёты: `node test.js`; КЕО по модели: `node bim/test-bim.js` |
| `INSTRUCTION.md` | Методика, принятые решения, журнал |

## Сборка и проверка
```
node test.js        # все проверки должны пройти
node bim/test-bim.js  # КЕО по модели: пространства, единицы, фонари, ориентация
node bim/verify-side.js  # независимая проверка бокового света (интегрирование по небу МКО); с bim/verify/1226-L01.json — помещения модели 1226
node bim/verify-top.js   # границы прямой составляющей верхнего света (пом. 71 модели 1226)
python3 build.py    # собрать dist/ и docs/index.html
sh bim/build.sh     # собрать bim/keo-bim.js и docs/keo-bim.js
```
