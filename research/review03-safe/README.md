Дата: 21.10.2026. База: `fe510f22177877ba29284bdf1f8535f1427fa2f1`.
Публикация в main разрешена автором 21.10.2026. Пакет не подтверждает нормативную правильность всех расчётов.

## Матрица закрытия

| Пункт | Реализовано | Ограничения |
|---|---|---|
| 1. Размеры и H | Уточнены направления dп/bп. Проверено, что H уже необязательна при стандартном или ручном ρср. Условный потолок подписан. | H по-прежнему нужна для автоматических площадей; неизвестная высота не восстановлена из геометрии. |
| 2. Перекрытия и Δs | При ошибке бокового ввода доступна диагностическая схема, без КЕО, расчётных лучей и PDF. Δs явно относится к точке А и показана отдельно от оси помещения. | Ошибка перекрытия не «исправляется» удалением окна/увеличением допуска. Для комбинированного режима диагностика ошибок не расширена. |
| 3. По общим | Поле показывает текущее применяемое значение; при изменении общих параметров обновляется. Ручное значение сохраняется в состоянии и возвращается при выборе «Вручную». | UI проверен DOM-двойником, не реальными браузерными кликами. |
| 4. Противостоящие фасады | Плоскости фасадов показаны на боковом плане по l/a/off, с номерами и легендой, для каждой стены. | Глубина зданий не выдумана; комбинированный план не расширен; остаётся схема №1 с параллельным фасадом. |
| 5. Смещение центра | Подсказка и пример объясняют off относительно линии через А; от оси комнаты центр = Δs + off. | Существующий контракт и числа не изменены; координаты реального проекта не установлены. |
| 6. Обе нормы | В результате, разборе и PDF показаны ЕО/СО; ручная норма применяется только к выбранной системе. Альтернатива не получает вердикта. | Сравнение не разрешает переход на СО и не проверяет искусственное освещение. При отсутствии нормы вывод нейтральный, а не ложное «не соответствует». |

## Что не исправлялось

- Формулы, нормативные таблицы, коэффициенты и округление не менялись; engine.js/data.js идентичны базе.
- Экстраполяция K по выносу козырька за пределы таблицы Б.19 (например, >3 м) не получила нового нормативного обоснования. Примечание разрешает экстраполяцию по глубине помещения; это не доказательство разрешения по выносу элемента. Формула не подменена, новый статус блокировки вердикта не вводился. Такой K нельзя считать подтверждённым только из-за наличия числа в калькуляторе.
- Не выполнена повторная сверка оригинального DOCX/его скриншотов в этой реализации: использован ранее извлечённый перечень шести замечаний.
- Не выполнены браузерные клики, загрузка JSON и скачивание/печать PDF в браузере: тестовая страница недоступна разрешённому облачному браузеру. Необходимо завершить эту проверку перед выпуском.
- При подготовке main и сайт не менялись; после отдельного разрешения автора пакет переносится в main. Исследовательская BIM-ветка не затрагивается. Обязательные BIM-сборки включают обновлённую общую модель полного отчёта (нормы/схемы/тексты), но не изменения алгоритмов Viewer; численная регрессия идентична базе.
