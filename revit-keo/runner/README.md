# D3 — локальный вызов исходного калькулятора

Реализация [ТЗ v0.3.0, разделов 2/6/7/8](../../tasks/KEO_REVIT.md). `client.py` (Python) запускает `runner.cjs` (Node) отдельным процессом без shell. Модуль читает **существующий** state v:1, вычисляет теми же `KEO.migrate/compute`, проверяет повторный импорт и возвращает результат. Это транспорт предварительного расчёта, не адаптер геометрии или подтверждение исходных данных.

## Вход и выход

Один UTF-8 JSON на stdin (до 2 MiB), до EOF:

```json
{
  "schema": "keo-revit-input-preview/0.1",
  "room": {"documentKey": "synthetic-document", "uniqueId": "synthetic-room"},
  "state": {"v": 1, "mode": "side", "side": {}, "top": {}}
}
```

Это пример структуры, **не готовый расчёт**: заполнить активные поля по [INPUTS.md](../INPUTS.md). Нет нужного поля — `missing-active-inputs` с путями, без подстановки типовых размеров. Числовые ограничения и формулы проверяет исходное ядро. Неактивная геометрия не запрашивается из BIM; контейнеры `side/top` сохраняют совместимость импорта. Проверка наличия не доказывает достаточность или происхождение входов.

Один JSON на stdout, код процесса 0 при успешном preview, 2 при отказе. Схема `keo-runner-preview/0.1`, поля: `ok`, `room`, `core` (SHA-256 модулей/совокупный хеш и исходная ревизия), `inputSha256`, `coreResult` (полный результат KEO), `previewImportJson`, `migrationNotes`, `issues/errors`. Статус **всегда серый**: PENDING при численном результате, ERROR при ошибке. `previewOnly=true`; `coreResult.pass` — ответ ядра на переданные числа, не разрешение окрашивать Room. D4 отдельно проверяет реальные входы и нормативную применимость.

`core-manifest.json` закрепляет пять неизменённых файлов в корне репозитория: `data.js`, `report.js`, `engine.js`, `schemes.js`, `model.js`. Загружаются оригинальные исходники в VM-контексте без `require`, сети или DOM. Хеши проверяются до исполнения; файлы пакета должны сохранить исходные UTF-8/LF байты (при checkout не преобразовывать LF в CRLF). `bridge.js` переиспользуется без изменения. Manifest — фиксация версии, не цифровая подпись и не граница безопасности для постороннего исполняемого кода.

## Python и установленный runtime

```python
response = calculate(envelope, node_executable, runner_path,
                     timeout_seconds=30, cancelled=cancel_callback)
```

Оба пути абсолютные и задаются локальной конфигурацией. Текущая папка не влияет на поиск JS-модулей; Node запускается скрыто без консоли. Клиент исключает `NODE_OPTIONS/NODE_PATH`, ограничивает вход/выход, проверяет JSON/код процесса, при ошибке/отмене/тайм-ауте завершает дочерний процесс и не принимает результат. Callback опрашивается не реже чем раз в 100 мс между ожиданиями; он не должен обращаться к Revit API из другого потока.

На MRM проверен уже установленный Node **24.19.0**, внешние Python-тесты и CPython **3.11.0** внутри Dynamo/PythonNet3. Это не обещание готового установщика: на другом ПК нужен явно установленный совместимый Node и проверка D0/D3; нельзя зависеть от пути runtime Codex. Интернет/AI/MCP не нужны для самого вычисления.

Пять схем проверены по полному результату и round-trip. Отмена/тайм-аут проверены на отдельном медленном процессе; тест подмены ответа не допускает ложный PASS.

## Граф Dynamo

`build-d3.cjs` включает оригинальные D0 guards, `client.py`, `d3_probe.py` в `KEO_D3_CoreReplay.dyn`: три входа, Manual, путь пустой, False. Он **только** проверяет синтетический обмен; не извлекает реальные расчётные поля Room.

1. Локально заполнить `config.d3.example.json`: защитные путь/хеш/build **существующей** тестовой RVT, абсолютные пути Node/runner, файл массива 1–5 синтетических запросов и отдельный D3 журнал `.jsonl`. Не публиковать частную конфигурацию. Запросы создаются `candidate(KEO, mode, system)` из `fixtures.cjs`; все содержат `meta.code=SYNTHETIC`.
2. Создать пять запросов без ручного ввода чисел можно из корня репозитория:

```sh
node -e "const fs=require('fs'),k=require('./revit-keo/runner/runner.cjs').loadCore().KEO,f=require('./revit-keo/runner/fixtures.cjs').candidate;fs.writeFileSync('d3-synthetic.local.json',JSON.stringify([['side','shaft'],['top','shaft'],['top','b2'],['comb','shaft'],['comb','b2']].map(x=>f(k,...x))))"
```

3. После ручного ответа на запрос доверия Dynamo указать путь конфигурации. False + Run — отмена до API. True + новый номер — прогон. Повторить с новым номером; сравнить ответы, снимки/хеши. Вернуть False. Не сохранять RVT или публичный граф с частными входами.

**Реально проверено 24.10.2026:** точный D3 bundle в уже открытом трёхвходовом D2-каркасе, два идентичных прохода пяти схем, False до/после. IsModified=false, версия/хеши прежней копии и оригинала неизменны. Синтетические КЕО 1.11 / 1.42 / 7.03 / 2.47 / 8.08 % не относятся к реальному Room. [Протокол](../validation/2026-10-23-build.md#d3-локальный-вызов-ядра).

**Открыто:** отдельное открытие сохранённого D3 `.dyn`, Player и доступная пользователю отмена длительного расчёта в Dynamo, упаковка для другой установки. Наличие Python callback не означает готовую кнопку отмены. D2.2/D4 — реальные входы и Room; D5 — карточки, цвета и марки. Полное исследование всех материалов/тел не является зависимостью этих задач.
