# D2 — диагностическое исследование геометрии

**Актуальный порядок по уточнению автора 24.10.2026:** этот граф — дополнительная диагностика. Для первого расчёта нужны только активные поля [карты входов](../INPUTS.md), полученные из проверенных параметров/необходимых измерений/явного ввода. Не требуется устранять все неизвестные материалы/кривые перед D4; блокируются лишь зависящие от них входы. Ниже сохранены факты и ограничения исследовательского прохода, а не обязательный объём рабочего адаптера.

24.10.2026: D2 расширен до физических тел окон, дверей и витражных панелей. В Revit прочитаны 69 элементов: 81 тело и 644 грани; два захвата идентичны, отмена до чтения подтверждена. Все 42 офлайн-теста прошли. Есть 20 элементов без тел, 160 граней без материала, неподдержанные кривые/поверхности и одно расхождение bbox. Это диагностические данные, не принятые световые проёмы. Полный D2, видимость и затенение остаются открытыми; RVT не изменены.

Требования — [ТЗ](../../tasks/KEO_REVIT.md), доказательства — [протокол](../validation/2026-10-23-build.md#d2-физические-тела-и-материалы).

## Физическая геометрия

`d2_geometry.py` добавляет Fine-геометрию кандидатов Windows/Doors/CurtainWallPanels: вложенные GetSymbolGeometry/Transform, тела в корневых координатах, грани/материалы и локальные IsPointInRoom-пробы. Прозрачность отображения не является τ. Empty solids, неразрешённые материалы, неподдержанные кривые/поверхности и bbox mismatch не устраняются предположениями. Никаких принятых проёмов или видимости этот экспорт не создаёт.

## Состав

- `d2_inspect.py` переиспользует D0/D1 проверки документа/build/hash и выбора Room. Читает 3D-оболочку через SpatialElementGeometryCalculator, нативные границы граней и ссылки на элементы, сформировавшие границу.
- Категории кандидатов: стены, окна, двери, витражные панели/импосты, перекрытия, кровли, потолки, колонны и обобщённые модели. Поиск в root document; пересечение XY bbox Room с запасом 4 ft, без ограничения высоты/фазы/варианта. Фаза/вариант сохраняются для последующей проверки. Это исследовательский охват, не полный набор затеняющих объектов.
- Читаются host/children/FromRoom/ToRoom, FindInserts и состав CurtainGrid, отдельная инвентаризация ImportInstance с transform/ownerView. Отсутствующие bbox и ошибки явно сохраняются; более 2000 кандидатов дают отказ.
- `build-d2.cjs` встраивает D0/D1/D2 в `KEO_D2_GeometryInspection.dyn`; внешний Python sys.path не требуется. Граф Manual, пустой путь/False.
- `config.d2.example.json`: заполнить локально путями/независимым хешем прежней копии и точным выбором фазы/Room/параметра из D1. Реальные конфигурации/журналы вне Git.

## Запуск и проверка

После ручного ответа на предупреждение доверия Dynamo ввести путь локальной конфигурации. False + Run проверяет отмену; True + новый номер запуска выполняет чтение. Изменение файла конфигурации само по себе не инвалидирует кэш Dynamo: менять номер запуска. Сверить два результата payloadSha256 и снимки документа, вернуть False, проверить хеши RVT. Не сохранять RVT и публичный граф с приватными входами.

```sh
node revit-keo/dynamo/build-d2.cjs --check
python -B -m unittest discover -s revit-keo/dynamo -p 'test_*.py'
```

Семь D2 тестов проверяют отбор кандидатов по XY независимо от высоты, schema/selection, отсутствие изменения конфигурации, отмену до API и диагностические флаги. Дополнительно проверяется явный вызов фазового getter без обращения к обычному свойству FromRoom/ToRoom. Добавлены четыре теста геометрического обхода и проверок bbox. Всего с D0/D1 — 42. Живой Revit interop проверен отдельно двумя захватами конечного bundle.

## Пределы

Схема `keo-dynamo-d2-inspection/v1` — диагностическая, не вход калькулятора. Даже CAPTURED_DIAGNOSTIC не означает готовность D2. `d2Complete`, `geometryAccepted`, `normativeAccepted` остаются false.

Оболочка Room может перекрывать реальные отверстия: её нельзя использовать вместо физической геометрии для затенения. Bbox не является площадью остекления, материалом или доказательством принадлежности проёма. Физические грани и материалы прочитаны диагностически; подтверждённое выделение световых отверстий, светопропускание, срез 1,2 м и воспроизводимые лучи ещё не реализованы. Linked/nested geometry, удалённое окружение и категории вне списка не покрыты. Ошибки и неподдержанные кривые не заменяются нулями или условными прямоугольниками.

Среда — проверенная D0/D1 установка MRM; для иной установки повторить D0. Запись, транзакции и Save/SaveAs отсутствуют. Обновлённый сохранённый D2-граф открыт и дважды испытан в Revit. Player не проверен. После прохода граф оставлен открытым в Manual/False, приватные входы на диск не сохранены.
