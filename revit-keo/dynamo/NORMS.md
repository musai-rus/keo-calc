# Нормативный отбор перед расчётом Room

Проверено 24.10.2026 для первых тестовых назначений. Это протокол разработки, не новый нормативный справочник и не изменение формул калькулятора. Экземпляры СП прочитаны на Google Диске по указателю [INSTRUCTION.md, раздел 8](../../INSTRUCTION.md#8-исходные-материалы); сетевые источники приведены ниже. Полные документы и проектные данные в Git не включаются.

|---|---|---|
| Комната переговоров | СП 367.1325800.2025, таблица А.1, строка 11; СП 52.13330.2016 с изм. 1, 2, таблица Л.1, строка 11 | В строке нет нормируемого КЕО. При подтверждённой функции — EXCLUDED, серый «КЕО не нормируется». Принадлежность к административному блоку не делает помещение рабочим кабинетом. |
| Административный рабочий кабинет | СП 367, таблица А.1, строка 1; СП 52, таблица Л.1, строка 1; СанПиН 1.2.3685-21, таблица 5.25, строка 1 | УРП 0,8 м. При ЕО: верхний свет 3%, боковой 1%; при СО: 1,8% / 0,6%. Для текущего опыта выбран ЕО; СО из старого расчёта автоматически не переносится. |

Назначение устанавливается по фактической функции, а не поиском подстроки в названии. Наличие постоянных рабочих мест или специального оборудования может требовать другой строки. Неизвестная функция — PENDING, а отсутствие строки в DATA не означает отсутствие нормы.

Для верхнего света проверяются **вместе**:

- среднее КЕО на характерном разрезе — СП 52, п. 5.5; СП 367, п. 8.5.2 и формула (Б.10);
- при размере по разрезу более 4 м — не менее пяти точек, крайние по 1 м от стен (СП 367, п. 8.5.2);
- равномерность и минимальное значение в точках — СП 52, п. 5.13: минимум/среднее не менее 1/3 и каждая точка не ниже нормы бокового света для соответствующей функции/системы.

Одного `coreResult.pass` недостаточно для принятия BIM-результата. Все применимые нормативные критерии, схема и входы должны иметь доказательства. Проверка минимума по точкам входит в приёмку D4; отдельный автоматический gate ещё не реализован. Ядро не менялось.

## Использование АР3

В проектном АР3 найден пример административного кабинета с верхним светом. Проверены схема пяти точек, формулы, отражённая составляющая, среднее и равномерность. Округлённая арифметика таблицы воспроизводится; расчёт по тем же опубликованным исходным данным в текущем ядре отличается менее чем на 1% из-за промежуточных коэффициентов и округлений. В частности, значение q в одной точке отчёта не совпадает с текущей формулой. Подгонка и перенос старой редакции в ядро не выполнялись; точного совпадения методик не заявляем.

В текущей модели отличаются отверстие и световой канал. Параметр высоты семейства не описывает всю шахту, а графическая прозрачность материала не равна τ. Поэтому геометрия текущего Revit берётся отдельно; пользователь подтвердил набор АР3 как проектные настройки с проверкой происхождения. Паспорт будущего изделия не требуется. Для сложного ступенчатого канала сначала проверяется применимость эквивалентной схемы. Пробный JSON и полное численное сравнение с калькулятором сохранены локально, нормативный статус остаётся PENDING.


## Аудит коэффициентов после уточнения автора

Проектный расчёт не требует выбранной марки стеклопакета, паспорта изделия или оптических свойств Revit-материала. Использовать нормативные таблицы/формулы для явно выбранной расчётной категории и допустимые нормативные значения при неизвестных характеристиках; остальные принятые проектные допущения подписывать с основанием. АР3 — проверяемый ориентир, а не безусловный источник истины. Различать предписанное нормой значение, выбор строки/диапазона и проектное допущение. Отсутствие данных производителя само по себе не блокирует расчёт, но произвольное число не становится нормативным.

| Поле | Найденное основание | Статус в текущем тесте |
|---|---|---|
| ρ помещения = 0,55 | СП 367, примечание 2 к таблицам Б.6/Б.7; реализованный режим калькулятора при неизвестной отделке | Нормативное значение по условию; используется существующий `rhoMode=default`. |
| MF = 0,67 | СП 367, таблица 5.1: нормальная среда, наклон 0–15° | Нормативный выбор по условиям и измеренному наклону. |
| τ2 = 0,75 | СП 367, таблица Б.15: категория деревянных спаренных переплётов | Число существует в норме, но категория тестового переплёта не подтверждена: АР3 описывает металлический переплёт. В тесте — принятое проектное значение по АР3, не измерение Revit и не подтверждение деревянной категории. |
| ρ стенок шахты = 0,70 | АР3; кривая 0,7 на рисунке Б.2 СП 367 используется для определения Kc | Принятое проектное значение; сам график не предписывает такую отделку каждой шахте. |

Аудит выполнен по экземпляру СП на Диске и [сетевому тексту СП](https://base.garant.ru/413556310/). Значение поправочного K1 из таблицы 8.1 нельзя выдавать за одноимённое численно τ2: проверяются символ, назначение коэффициента и строка. Если проектный набор уточняется, пересчитывается тот же Room без нового RVT и без правки формул.

## Проверка происхождения τ1 = 0,48 по переписке и исходникам

24.10.2026, дополнительная проверка по просьбе автора. В Slack #keo-calculator найдена сверка верхнего КЕО от 15.10: 0,48 указано как τ1, 0,75 как τ2, их произведение — 0,36. Прочитаны исходные замечания по верхнему свету, ответ от 14.10, «Корректировка_03» и отчёт по ней; отдельно визуально просмотрены все 9 встроенных изображений двух файлов замечаний. Исправление τ1 с 0,48 на 0,40 в проверенных материалах не найдено.

На скриншоте верхнего света поле «Остекление верха τ1» содержит 0,48; подпись интерфейса «по паспорту; ≈0,48–0,8» не является нормативной ссылкой. Правки этого документа касаются числа точек и координат фонарей. Значения 0,4 на скриншоте «Корректировка_03» относятся к отражению противостоящих фасадов ρф. Ни ρф, ни Kc светового канала нельзя подставлять вместо τ1.

АР3, раздел 2 и общие параметры проекта, описывает однокамерное заполнение с солнцезащитным и энергосберегающим покрытием в металлическом переплёте и отдельно задаёт τ1=0,48, τ2=0,75. В коде текущего калькулятора 0,48 также присутствует в исходном шаблоне фонаря; это не вычисление по DATA. Наличие значения в отчёте и шаблоне установлено, но цепочка его первоначального выбора подрядчиком не документирована.

СП 367.1325800.2025, Б.2.7 / Б.14: для категории 6СИ–16–4М1 указан диапазон 0,40–0,71 и отдельное 0,74; для 6СИ–16–4М1–12–4М1 — 0,36–0,64. Примечание 3 связывает диапазоны с различием светотехнических характеристик. 0,48 лежит внутри диапазона, но из этого не следует предписание выбирать 0,48, 0,40 или середину диапазона. Точная категория АР3 не установлена лишь по словесному описанию; соответствие строке остаётся гипотезой. В проверенном базовом тексте редакции 2017, таблицы А.7/А.8, отдельного предписанного τ1=0,48 также не найдено; полнота всех изменений старой редакции не заявляется.

Уточнение к τ2: 0,75 в таблице Б.15 редакции 2025 соответствует деревянным спаренным переплётам, а в АР3 указаны металлические. В базовой редакции 2017 значение 0,75 есть также для одинарных открывающихся стальных переплётов окон/фонарей промышленных зданий (А.9); это не доказывает применимость данной категории к тестовому общественному зданию. Поэтому принятый пользователем τ2 сохраняется именно как проектное значение АР3, без выдуманного подтверждения категории переплёта.

Для текущего опыта ранее принятое пользователем τ1=0,48 не меняется автоматически. Его основание — проектное допущение по АР3; нормативный статус источника — «точный выбор не подтверждён». Потребности в марке/паспорте будущего изделия это не создаёт. Перед численным выводом сценарий и это допущение должны быть видимы; источники коэффициентов не заменяются скрытыми defaults. Геометрическая приёмка фонаря и окончательная марка остаются отдельной незавершённой работой.
