# D0 — проверка среды Dynamo без изменения модели

Этот срез только читает версии среды, состояние сохранённого тестового документа и число Rooms. Геометрия, нормы и КЕО не рассчитываются. ТЗ и этапы — [`tasks/KEO_REVIT.md`](../../tasks/KEO_REVIT.md), выполнение — [Issue #13](https://github.com/musai-rus/keo-calc/issues/13).

Следующий срез: [D1 — выбранный Room, нативные контуры и независимые метрики](D1.md). D0 остаётся отдельной проверкой среды.

## Файлы

- `d0_probe.py` — исходник Python для PythonNet3; не использует TransactionManager, создание элементов, Save/SaveAs или загрузку собственного C#-аддина.
- `KEO_D0_ReadOnly.dyn` — граф из трёх входов, Python-узла и Watch. Режим Manual; чтение выключено по умолчанию.
- `build-graph.cjs` — воспроизводимая генерация графа из Python-исходника с его SHA-256. После правки Python выполнить `node revit-keo/dynamo/build-graph.cjs`; проверка синхронности: добавить `--check`.
- `config.example.json` — шаблон локальной конфигурации. Пустые пути/хеш намеренно не позволяют читать модель.
- `test_d0_probe.py` — проверки отказов и контроля неизменности на двойнике; они не заменяют запуск в Revit.

## Запуск

1. Использовать **существующую согласованную standalone копию** в отдельном сеансе Revit. Исходник не открывать для теста, новые RVT на каждый прогон не создавать.
2. В локальном JSON по шаблону указать полный путь этой копии, независимо полученный SHA-256, ожидаемые VersionNumber/VersionBuild. Не брать хеш из первого результата графа, чтобы автоматически принять неизвестную модель. Не коммитить конфигурацию, реальные пути и evidence.
3. При необходимости задать `evidence_jsonl`: полный путь локального файла `.jsonl`. Граф дописывает туда один результат на фактический запуск; RVT открывается только на чтение. Без этого поля результат доступен в Watch. Каталог должен существовать.
4. Открыть граф в Dynamo. Пользователь самостоятельно отвечает на штатные запросы доверия/сбора данных; отключение защиты или постоянное доверие папке для этого среза не требуется.
5. Ввести путь конфигурации в первый вход. При `False` нажать «Запуск»: ожидается `CANCELLED`, без обращения к Revit API. Это отмена **до чтения**, не проверка остановки длительного вычисления.
6. Выбрать `True`, запустить. Успех среды — `READ_ONLY_OK`, одинаковые before/after, `documentUnchanged=true`. Проверяются активный документ, сохранённая standalone-модель, отсутствие несохранённых изменений/транзакции и совпадение SHA-256/build.
7. Для повторного фактического чтения изменить Run number. Простое повторное нажатие Run может использовать кэш Dynamo; доказательство повторения — новый runId и новая запись журнала.
8. После испытания проверить хеш оригинала и копии независимо снаружи, вернуть вход чтения в False. Не сохранять RVT; приватные входы графа не включать в публичную версию `.dyn`.

## Границы доказательства

`READ_ONLY_OK` подтверждает только ограниченный D0-проход. Все признаки приёмки модели/геометрии/норм остаются false. Неизменность хешей и IsModified до/после не доказывает точность геометрии или отсутствие промежуточных изменений вне интервала. Файл читается с FileShare.ReadWrite, поскольку Revit держит его открытым; совпадение снимков не является блокировкой других писателей. Любой отказ API или контрольной проверки даёт REFUSED/ERROR, а не нулевые Rooms или КЕО.

Встроенные версии PythonNet3/Dynamo/Player фиксировать по фактической установке и runtime; не заявлять поддержку других Revit на основании этого теста. Player-сценарий и остановка длительного расчёта проверяются отдельно. Сторонние пакеты для этого графа не требуются.

Офлайн: `python -B revit-keo/dynamo/test_d0_probe.py`, затем `node revit-keo/dynamo/build-graph.cjs --check`. Расчётное ядро не импортируется и не меняется.
